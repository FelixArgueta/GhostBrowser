# GhostBrowser

A privacy-focused Electron browser that blocks cookies and ads by default.

## Features

- **Cookie Blocking**: Prevents websites from tracking you via cookies
- **Ad Blocking**: Comprehensive ad blocking using EasyList filters
- **Minimal Interface**: Clean, distraction-free browsing experience
- **Right-Click New Window**: Easy tab management
- **Open Source**: Transparent privacy protection

## Quick Start

### Prerequisites
- Node.js (v14 or later)
- npm

### Installation

1. Clone the repository
```bash
git clone https://github.com/FelixArgueta/GhostBroswer.git
cd GhostBroswer
```

2. Install dependencies
```bash
npm install
```

3. Run the browser
```bash
npm start
```

## Development

### Available Scripts
- `npm start`: Launch the browser
- `npm run dev`: Run in development mode

## Privacy Approach

GhostBrowser is designed with privacy as the core principle:
- No cookie tracking
- Built-in ad blocker
- Minimal data retention
- No telemetry
